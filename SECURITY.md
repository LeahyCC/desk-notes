# Security

## Supported versions

Only the latest release gets fixes.

## Reporting a problem

Please report it privately through [GitHub's private vulnerability reporting](https://github.com/LeahyCC/desk-notes/security/advisories/new). Do not open a public issue.

Say what the problem is, how to reproduce it, and which version you used. You should hear back within a week.

## Scope

DeskNotes runs locally, makes no network calls, and keeps notes as plain files in `%APPDATA%\DeskNotes\`. Useful reports are things like a crafted note file that crashes DeskNotes or makes it write outside its own folder.
